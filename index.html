입주 기간 중·후 관리 방안

분기별 성과 점검(매출·고용·기술개발 현황)을 실시하고 전담 멘토(산학협력중점교수)를 배정하여 맞춤형 컨설팅을 제공합니다. 성과가 미흡한 기업에는 추가 컨설팅을 제공하며, 입주 종료 후에는 졸업기업 성과 모니터링 체계를 구축해 투자·매출·고용 성과를 지속 관리하고, 우수 졸업기업이 후배 창업기업의 멘토로 참여하는 선순환 구조를 강화합니다.

    BACKEND · GITHUB / GOOGLE SHEETS
    데이터 저장 연동
    이 대시보드의 입력값(예산 집행액·프로그램 KPI·진행상태·환류사항)은 기본적으로 브라우저 세션에만 저장됩니다. 아래 두 방법 중 하나를 연결하면 값이 실제로 저장되어 다른 기기·다음 방문에서도 이어서 볼 수 있습니다. 두 방법을 동시에 켜둘 필요는 없고, 마지막으로 연결한 쪽이 저장 대상이 됩니다.

    방법 A · GitHub 저장소 (권장 · 배포 과정 없음)

    GitHub 저장소에 campustown-data.json 파일 하나를 만들어 두면, 저장하기를 누를 때마다 GitHub API로 그 파일을 갱신(커밋)합니다. Google Apps Script 배포 과정이 필요 없어 설정이 더 간단합니다.

    연동되지 않음
    보안 주의 : 이 토큰은 브라우저에서 GitHub API로 직접 전송됩니다. 반드시 이 저장소 하나에만 쓰기 권한을 준 fine-grained 토큰을 사용하고, 공용 PC에서는 사용을 피하세요. 유출이 의심되면 즉시 GitHub에서 토큰을 삭제(Revoke)하세요.

    토큰 만들기 (최초 1회, 약 3분)

    1. GitHub에 로그인 후, 데이터를 저장할 저장소를 하나 생성합니다 (Public/Private 무관, Private 권장). 예: campustown-data
    2. 우측 상단 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens로 이동합니다.
    3. Generate new token 클릭 → Resource owner는 본인 계정, Repository access는 "Only select repositories"로 방금 만든 저장소만 선택합니다.
    4. Permissions → Repository permissions → Contents를 Read and write로 설정합니다.
    5. Generate token 클릭 후 나오는 토큰 문자열을 즉시 복사합니다 (다시 볼 수 없습니다).
    6. 위 입력창에 계정명·저장소명·토큰을 넣고 "연결 및 불러오기"를 누릅니다. 파일이 아직 없다면 "저장 시 새로 생성됩니다"라고 표시되며, 처음 저장하기를 누르는 순간 파일이 생성됩니다.

    방법 B · Google Sheets (Apps Script 배포 필요)

    연동되지 않음

    설정 방법 (Google Sheets, 최초 1회, 약 5분)

    1. Google Sheets에서 새 스프레드시트를 하나 만듭니다. (제목은 원하는 대로, 예: "캠퍼스타운 대시보드 DB")
    2. 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다.
    3. 기본으로 열려있는 Code.gs 내용을 모두 지우고, 아래 코드를 그대로 붙여넣습니다.
    4. 상단의 저장(💾) 후, 배포 → 새 배포를 클릭합니다.
    5. 유형 선택에서 웹 앱을 고르고, "실행 계정: 나", "액세스 권한: 전체 허용(익명 포함)" 으로 설정한 뒤 배포를 누릅니다.
    6. 권한 승인 화면이 나오면 본인 계정으로 승인합니다.
    7. 배포가 끝나면 나오는 웹 앱 URL(…/exec 로 끝나는 주소)을 복사해, 위 입력창에 붙여넣고 "연결 및 불러오기"를 누릅니다.
